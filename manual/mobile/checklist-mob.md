# Чек-лист ручного тестирования — Mobile (Android)

Функциональность, которая не покрыта автотестами (см. `mobile` модуль) или физически не может быть
автоматизирована через Appium (push-уведомления, поведение ОС, распознавание речи).

Полные тест-кейсы с шагами в [test-cases.md](test-cases-mob.md).

## Push-уведомления
- [x] Уведомление о задаче со сроком приходит вовремя
- [x] Тап по уведомлению открывает нужную задачу
- [x] Уведомление корректно отображается при свёрнутом приложении
- [x] Уведомление корректно отображается при полностью закрытом приложении

## Голосовой ввод (Ramble)
- [x] Запуск голосового ввода задачи
- [x] Распознанный текст корректно превращается в задачу
- [x] Отмена голосового ввода на середине записи - битые / пустые задачи не создаются

## Офлайн-режим
- [x] Создание задачи без сети — сохраняется локально, в интерфейсе есть предупреждающая плашка
- [x] Синхронизация локально созданной задачи при восстановлении сети — без дублирования
- [x] Редактирование задачи офлайн — работает через оптимистичный UI (изменения видны сразу,
  до ответа бэкенда)

## Жизненный цикл приложения
- [x] Сворачивание приложения с открытой панелью деталей задачи — состояние и введённый текст
  сохраняются при возврате
- [x] Принудительное закрытие через диспетчер задач и повторный запуск — сессия остаётся активной

## Расширенное редактирование задачи
- [x] Установка срока через календарь
- [x] Изменение приоритета
- [x] Добавление метки
- [x] Создание подзадачи

## Отображение списка (сортировка и фильтры)
- [x] Переключение режима отображения (Список / Доска / Календарь) через шторку «Отображение»
- [x] Применение фильтра по приоритету, список перестраивается в соответствии с фильтром

## Поиск
- [x] Поиск задачи по точному совпадению названия с вкладки «Обзор» — результат открывает нужную задачу
- [x] Поиск задачи по частичному совпадению — находит по отдельному слову из названия
- [x] Поиск не находит несуществующую задачу — корректное пустое состояние (иллюстрация, текст,
  ссылка «Искать в выполненных»)
- [x] Поиск учитывает задачи из разных проектов одновременно 

## Внешний вид
- [x] Переключение светлая / тёмная тема (вручную и «как в системе») — багов контрастности нет
- [x] Поворот экрана в landscape на экранах «Входящие», «Задача», «Календарь» — нижняя навигация
  корректно трансформируется в левый сайдбар (Navigation Rail)
- [x] Корректность отображения на разных плотностях экрана (проверено на одном устройстве)

## Интеграция с ОС
- [x] Создание задачи через share-меню из другого приложения (например, из браузера)
