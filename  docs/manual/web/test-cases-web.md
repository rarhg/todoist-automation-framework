# Тест-кейсы — Web

10 кейсов, отсортированы по приоритету. Покрывают функциональность, которая не автоматизирована или не может быть автоматизирована
(вход — форма защищена капчей, см. `LoginTest`).

Окружение: Chrome (153.0.8010.53), `https://app.todoist.com`, тестовый аккаунт проекта.

---

## WEB-01 — Успешный вход в аккаунт

**Приоритет:** Критический \
**Предусловие:** Пользователь разлогинен (открыт экран приветствия)

| Шаг | Действие                                            | Ожидаемый результат                                              |
|---|-----------------------------------------------------|------------------------------------------------------------------|
| 1 | Открыть `app.todoist.com`                           | Отображается экран приветствия с кнопками входа                  |
| 2 | Нажать «Войти через Email» => «Войти»               | Открывается форма с полями email и пароль                        |
| 3 | Ввести корректный email и пароль тестового аккаунта | Поля заполнены, кнопка «Войти» активна                           |
| 4 | Нажать «Войти»                                      | Пользователь авторизован, открывается экран «Входящие»           |
| 5 | Проверить сайдбар                                   | Отображается имя / аватар пользователя, список проектов загружен |

**Примечание:** форма входа Todoist периодически показывает капчу автоматизированному браузеру, поэтому сценарий не покрыт автотестом (`LoginTest`, `@Disabled`) и проверяется только вручную.

**Результат:** ✅ Пройден

## WEB-02 — Поиск задачи по названию

**Приоритет:** Высокий \
**Предусловие:** В Inbox существует задача с уникальным названием, например «Тестовая задача поиска»

| Шаг | Действие                                                              | Ожидаемый результат                                                     |
|-----|-------------------------------------------------------------------------|-------------------------------------------------------------------------|
| 1   | Открыть поиск (иконка / сочетание клавиш)                             | Открывается поле ввода поискового запроса                               |
| 2   | Ввести заведомо несуществующий текст                                  | Отображается пустое состояние «ничего не найдено», без ошибок в консоли |
| 3   | Ввести полное название задачи                                         | Задача появляется в результатах                                         |
| 4   | Очистить запрос и ввести часть названия (подстрока из середины слова) | Та же задача по-прежнему находится                                      |
| 5   | Ввести запрос в другом регистре (ЗАГЛАВНЫМИ)                          | Результат не меняется, поиск нечувствителен к регистру                  |
| 6   | Кликнуть на найденную задачу из результатов                           | Открывается панель деталей этой задачи                                  |

**Результат:** ✅ Пройден

## WEB-03 — Создание и работа с фильтром через модальное окно «Добавить фильтр»

**Приоритет:** Высокий \
**Предусловие:** Есть задачи с разными приоритетами и сроками

| Шаг | Действие | Ожидаемый результат |
|---|---|---|
| 1 | В сайдбаре перейти в раздел «Фильтры и метки» | Открывается список существующих фильтров и меток |
| 2 | Нажать «+» рядом с разделом фильтров | Открывается модальное окно «Добавить фильтр» с полями «Имя» (0/60), «Описание», «Цвет», переключателем «Добавить в избранное» и полем «Запрос» (0/1024) |
| 3 | Нажать значок «?» рядом с заголовком «Добавить фильтр» | Отображается блок «Примеры фильтров» с готовыми образцами синтаксиса запроса (например `30 дней`, `сегодня & p1`, `@ожидание`) |
| 4 | В поле «Имя» ввести название фильтра, например `Manual test filter` | Введённый текст отображается в поле, счётчик символов обновляется (например «17/60») |
| 5 | В поле «Запрос» ввести условие по приоритету в синтаксисе Todoist: `p1` | Текст отображается в поле, счётчик символов обновляется, кнопка «Добавить» становится активной |
| 6 | Нажать «Добавить» | Модальное окно закрывается, новый фильтр с указанным именем появляется в списке |
| 7 | Открыть созданный фильтр | Отображаются только задачи с приоритетом 1 |
| 8 | Отредактировать фильтр, заменив запрос на `today` | Список задач в фильтре обновляется согласно новому условию (задачи со сроком «сегодня») |
| 9 | Удалить фильтр (через контекстное меню) | Фильтр исчезает из списка, повторное открытие невозможно |

**Примечание:** поле «Запрос» использует собственный синтаксис фильтров Todoist (`p1`, `p2`,
`today`, `30 дней`, `@метка` и т.д.), а не свободный текст вида «priority 1» — при вводе
произвольного текста без учёта синтаксиса фильтр либо не найдёт ожидаемых задач, либо не
сохранится. Синтаксис есть в подсказке «Примеры фильтров» (шаг 3), к ней стоит обращаться при
формулировании условия.

**Результат:** ✅ Пройден
